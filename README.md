## 虛擬貨幣錢包到底是什麼？

虛擬貨幣錢包並不是把比特幣或以太幣「裝」在手機裡。區塊鏈資產仍然記錄在鏈上，錢包主要負責管理私鑰、助記詞和交易簽名，讓你可以控制某些鏈上地址。

常見的錢包類型可以分成兩大類。

### 交易所帳戶：平台代為保管私鑰

當你在中心化交易所買入 BTC、ETH 或 USDT 時，資產通常顯示在交易所帳戶中。你可以登入帳戶、查看餘額和下單，但私鑰一般不是由你直接保管。

這種方式對新手比較容易上手，因為忘記登入密碼時通常可以透過電子郵件、手機或身份驗證找回帳戶。不過，資產控制權和提幣權限仍然受到平台規則、地區限制和帳戶狀態影響。

### 自託管錢包：由自己保管私鑰

OKX Wallet 屬於自託管、多鏈錢包。官方說明指出，錢包的私鑰或助記詞由使用者控制，OKX 不會代替使用者保管錢包中的資產。自託管的好處是可以直接連接 DApp、DEX 和其他鏈上服務；代價是助記詞一旦遺失，通常沒有客服可以替你重設。

這也是虛擬貨幣錢包最重要的分水嶺：

- 交易所帳戶比較像平台內的資產帳本。
- 自託管錢包比較像你自己管理的鏈上鑰匙。
- 錢包地址可以公開分享，用來收款。
- 助記詞和私鑰不能分享，任何要求你提供助記詞的人都不可信。
- 發送交易後通常無法像銀行轉帳一樣直接撤回。

如果你只是剛接觸加密貨幣，先理解這幾點，比急著研究錢包支援多少條鏈更重要。

多鏈錢包的方便之處，是你不必為每一條鏈分別安裝不同工具。但方便也帶來一個常見風險：同名代幣可能存在於不同網路。例如 USDT 可能在 Ethereum、Tron、BNB Chain 或其他網路上發行。收款地址相同，不代表網路可以隨便選。

### Swap 與 DEX 交易

OKX Wallet 內建代幣交換功能，可以使用不同模式進行 Swap，並連接多個去中心化流動性池。官方將這項功能分為 Easy、Advanced 和 Meme Mode，實際顯示方式可能隨版本調整。

使用 DEX 時，畫面上看到的價格不一定等於最後成交價格，還要留意：

- 網路 Gas fee
- DEX 或路由服務費
- 價格滑點
- 流動性深度
- 代幣合約是否正確
- 交易是否需要授權
- 代幣是否存在釣魚或惡意合約風險

「Swap 成功」只代表交易被鏈上執行，不代表你買到的代幣一定有流動性，也不代表代幣價格會上升。

### 連接 DApp、NFT 和 DeFi

OKX Wallet 可以連接 DApp、NFT 市場、DeFi 服務以及支援 WalletConnect 的網站。官方學院資料也將 NFT、去中心化交易所和 DeFi 殖利率列為 OKX Wallet 的主要使用場景。

連接 DApp 時，最需要注意的是簽名內容。單純「連接錢包」和「批准代幣支出」不是同一件事。前者通常只是讓網站讀取公開地址，後者可能授權智能合約動用某種代幣。遇到不明網站要求無限額授權時，不要為了追空投就直接確認。

官方教學提到，建立錢包後應在處理資金前備份助記詞，並建議以紙筆記錄後放在安全位置。助記詞不是登入碼，也不是可以傳給客服的驗證資料。

### 助記詞應該怎麼保存？

比較穩妥的做法是：

- 以紙筆抄寫，不要只放在手機相簿。
- 不要透過 Messenger、LINE、Email 或雲端記事本傳送。
- 不要截圖後同步到雲端。
- 不要輸入任何所謂「官方驗證助記詞」的網站。
- 可以考慮分開保存備份，但必須確保自己知道如何完整還原。
- 不要把所有備份放在同一個容易被水、火或他人接觸的位置。

如果有人表示「你的錢包需要升級」「需要重新同步」「需要驗證助記詞」，先停止操作。官方 FAQ 也提醒，涉及錢包恢復、代幣遷移或要求連接不明網站的訊息，可能是釣魚詐騙。

## 第一次轉入 BTC、ETH 或 USDT 要注意什麼？

第一次使用虛擬貨幣錢包，最容易出錯的地方不是建立錢包，而是轉帳網路。

### 先確認幣種和網路

假設你要轉入 USDT，不能只確認「地址看起來一樣」。你還要確認：

- 幣種是否為 USDT。
- 發送方使用哪個網路。
- OKX Wallet 是否支援該網路。
- 收款頁面選擇的網路是否與發送方一致。
- 是否有最低入帳數量。
- 是否需要 Memo 或 Tag。

如果發送方選擇 Tron，而收款方選擇 Ethereum，資產可能無法正常到帳。某些錯誤可以透過客服或鏈上工具處理，但不應把「也許能找回」當成操作策略。

### 先小額測試，再轉完整金額

對新地址第一次轉帳時，先轉一筆小額測試。確認資產出現在正確網路和正確錢包後，再處理剩餘金額。這個步驟看起來保守，但鏈上轉帳沒有銀行客服可以直接撤銷交易，測試成本通常比錯誤轉帳的損失低很多。

### 留意 Gas token

每條鏈都有自己的交易成本。錢包裡只有 USDT，不代表一定能轉出 USDT。你可能還需要 ETH、TRX、BNB、SOL 或其他對應網路的原生代幣支付 Gas fee。

OKX 官方 FAQ 明確指出，Web3 Wallet 的網路費必須以該區塊鏈的原生加密貨幣支付，而且原生代幣必須位於正確的網路。

## 常見問題

### OKX Wallet 是冷錢包嗎？

不是。OKX Wallet 是軟體型自託管錢包，通常安裝在手機、瀏覽器或網頁環境中，屬於熱錢包使用方式。它可以搭配硬體錢包等其他安全方案，但不能把一般 App 錢包直接稱為冷錢包。

### 建立 OKX Wallet 需要先註冊交易所帳戶嗎？

官方教學指出，使用 App 的 Web3 功能不一定需要先連接 OKX 交易所帳戶。交易所帳戶和 Web3 Wallet 是不同功能，但兩者可以在部分操作中互相轉移資產。

### 忘記錢包密碼怎麼辦？

錢包密碼主要用於保護裝置上的錢包資料。如果仍然持有正確助記詞，通常可以在支援該錢包標準的 App 或錢包中恢復；如果助記詞和私鑰都遺失，單靠客服通常無法替你取回自託管資產。

### OKX Wallet 轉帳一定要付費嗎？

鏈上交易通常需要支付網路 Gas fee，金額會依網路和當時擁塞程度變化。某些 Swap 還可能涉及服務費或價格滑點。不要把「建立錢包免費」理解成「所有鏈上操作都免費」。

### 可以把助記詞交給客服嗎？

不可以。客服不應要求你提供完整助記詞或私鑰。任何要求你把助記詞輸入陌生頁面、傳送給他人或透過私訊驗證的做法，都應立即停止。
